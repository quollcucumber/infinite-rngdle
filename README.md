# Infinite RNGdle

An unlimited, unofficial take on [RNGdle](https://www.rngdle.com/): roll a random number from 0 to 1,000,000 as often as you like, collect badges, and see how rare your roll is.

- Pure static site (HTML/CSS/vanilla JS modules), no build step, no backend, no external requests. Stats live in `localStorage`.
- `js/badges.js` defines every badge. `js/calibration.js` is generated by scoring all 1,000,001 numbers, which sets each badge's EP and the roll-rarity distribution.

```sh
npm run calibrate   # regenerate js/calibration.js after changing badges
npm start           # serve on http://localhost:8080
```

When deploying changes, bump the `?v=` tags in `index.html` and the imports in `js/app.js` so browsers don't keep the old cached files (GitHub Pages caches for 10 minutes).
